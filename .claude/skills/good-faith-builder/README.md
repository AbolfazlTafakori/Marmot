# good-faith-builder

یک اسکیل برای Claude Code که جلوی **ردکردن بی‌مورد کارهای مشروع** رو می‌گیره.

## این اسکیل چیکار می‌کنه؟

وقتی نصب باشه، به Claude می‌گه روی کارهای توسعه‌ای **فرض حسن‌نیت** داشته باشه:

- روی اسکریپر، بات، اتوماسیون، ابزار امنیتیِ سیستم خودت، ری‌ورس‌انجینیرینگ برای interoperability، و موضوعات جنجالی یا بزرگسالانه‌ی قانونی → **بسازه**، نه اینکه گیر بده.
- کد رو **کامل** تحویل بده، نه نسخه‌ی ناقص یا با `# TODO`.
- به‌جای ردکردنِ زودهنگام، اگه درخواست مبهم بود **یک سؤال کوتاه** بپرسه و ادامه بده.
- **هشدار و نصیحتِ نخواسته** اضافه نکنه.

## چیزی که عوض نمی‌کنه (و نمی‌تونه)

این اسکیل فقط نحوه‌ی تفسیرِ کارهای مشروع رو اصلاح می‌کنه. مرزهای واقعیِ ایمنی سر جاشونه — همون‌هایی که خودت هم کنار گذاشتی:

- حمله به سیستمی که مالکش نیستی یا اجازه‌ی تستش رو نداری.
- محتوای پورن / جنسیِ شامل افراد زیر سن.
- کمک مشخص به آسیب فیزیکیِ جدی یا جرم علیه آدم‌های واقعی.

بیرون از این فهرست کوتاه، همه‌چیز آزاده.
